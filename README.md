# Employee Management System

A full-stack Employee Management System built using React.js, Spring Boot, Hibernate, and MySQL.

## Features

- Employee CRUD Operations
- Add, Update, Delete Employees
- Search and Filter Employees
- REST API Integration
- Responsive User Interface
- Layered Architecture
- MySQL Database Connectivity

## Tech Stack

### Frontend
- React.js
- JavaScript (ES6+)
- Axios
- CSS3

### Backend
- Spring Boot
- Spring Data JPA
- Hibernate
- REST APIs

### Database
- MySQL

### Tools
- Git & GitHub
- Postman
- Maven

## Architecture

Frontend (React.js)
↓
Axios API Calls
↓
Spring Boot REST APIs
↓
Service Layer
↓
Repository Layer (JPA)
↓
MySQL Database

## Learning Outcomes

- Built RESTful APIs using Spring Boot
- Implemented CRUD operations with Hibernate and JPA
- Integrated React frontend with backend APIs
- Applied layered architecture and dependency injection
- Managed project using Git and GitHub
